YOUR SPRITE CHECK QUEST
  1. FILE ใช้ Open/Save .DAT ด้านบน หรือ File → Reset Scene เพื่อกลับหน้าว่าง และ File → Update เพื่อตรวจแพตช์จาก GitHub
  2. OPEN เปิด PNG แล้วตั้งขนาดช่องใน GRID
  3. PAINT เลือกเฟรม แล้วเข้าแท็บ PAINT เพื่อวาด/ลบ/ดูดสี/เติมสี Alt + คลิกซ้ายเพื่อดูดสีชั่วคราว ใช้ Undo/Redo ร่วมกับไทม์ไลน์ 50 ขั้น และ SAVE EDITED PNG เพื่อส่งออกภาพที่แก้แล้ว ภาพต้นฉบับยังดูได้ใน Compare ด้านซ้าย
  4. PLAY ดับเบิลคลิกแถวเพื่อเล่นแอนิเมชัน ค่าเริ่มต้น Loop ทุกแถว
  5. DETECT ตรวจภาพที่ตรงกันทุกพิกเซล กลุ่มสีเดียวกันใช้ภาพซ้ำได้
  6. EDIT เลือกคีย์ ปรับ Hold เพิ่ม/ลบ/ย้ายคีย์ แล้วกด CONFIRM
  7. MERGE รวมภาพเพื่อสร้าง Sheet ใหม่ ส่วน COMPARE เข้าไปดู Original / Edited ได้ตั้งแต่เปิดไฟล์
  8. SAVE .DAT เก็บภาพต้นฉบับ GRID ไทม์ไลน์ FPS และผล Merge ไว้เปิดแก้ไขต่อด้วย OPEN .DAT
  9. SHORTCUTS Spacebar เล่น/หยุด, Ctrl+Z ย้อนกลับ, Ctrl+Y หรือ Ctrl+Shift+Z ทำซ้ำ เก็บประวัติล่าสุด 50 ขั้นต่อ session
  10. BACKGROUND เลือก Checkerboard หรือ Solid color และกดช่องสีด้านบน เปลี่ยนพื้นหลัง Sheet / Compare / Paint / Live Preview พร้อมกัน จำค่าเมื่อเปิดใหม่ โดยสีพื้นหลังไม่ติดไปกับ PNG
  11. LAYOUT ลากเส้นแบ่งเพื่อปรับความกว้าง/สูงของช่อง ดับเบิลคลิกคืนค่าช่องนั้น หรือ RESET LAYOUT คืนค่าทั้งหมด ใช้ Tab + ลูกศรปรับได้ และจำขนาดอัตโนมัติ
  12. EXPORT ดาวน์โหลด PNG และ JSON ไปด้วยกัน
COMPARE: เลือก Animation / Sprite Sheet, ซูม / 1:1 / Fit, ลากเพื่อเลื่อนภาพ, Sync view และปรับสัดส่วนซ้ายขวาได้ กด SHOW / HIDE COMPARE LOG เพื่อเปิด–ปิดตาราง ขนาด viewport จะขยายเมื่อปิด Log ตารางแสดงขนาดภาพและไฟล์จริงหลัง Merge
Within each row คงภาพแยกตามแถว ส่วน Share across rows อนุญาต JSON อ้างถึงภาพในแถวอื่น ชื่อท่าและหมายเลขแถวเดิมยังอยู่ครบ
Transparent cells are excluded on import. Add repeats with Hold or Duplicate. Unity reads the JSON through the included Unity/SpriteCheckPlayer.cs companion.
